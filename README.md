# Flux

Tes flux RSS et tes chaînes YouTube dans NeoDex, dans l'ordre de parution : pas d'algorithme, pas de
suggestions, seulement ce que tu suis. Les nouveautés s'affichent sur l'accueil.

- Colle le lien d'un flux RSS / Atom, ou celui d'une chaîne YouTube (`youtube.com/@nom`) : Flux trouve le flux tout seul.
- Mise à jour toutes les 30 minutes, même onglet fermé.
- Un clic ouvre l'article ou la vidéo ; **Tout lu** remet le compteur à zéro.

L'autorisation « réseau » couvre tous les sites, puisque tu choisis toi-même les flux à suivre.

## Installer

Dans NeoDex : **NeoStore → À découvrir → Flux → Installer**.

## Développer un plugin

Le format et le guide sont dans le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
